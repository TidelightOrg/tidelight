# Saved research evidence graph API

Agent Flow already returns a typed evidence graph for live research in its result. This API extends that provenance model to saved research briefs backed by the existing `research_sources` and `research_evidence` tables; it does not introduce another evidence store.

## Endpoint

`GET /api/research/evidence-graph/{researchRunId}` requires the authenticated owner of a run with `status = complete` and `summary.answer_status` equal to `source_matched_claims` or `insufficient_evidence`. Unknown, other-owner, non-complete, and ineligible records return HTTP 404. Responses are private, uncached, bounded to 90 source rows, 500 evidence rows, and 2,000,000 UTF-16 code units across emitted text fields. URL, title, publisher, content hash, source excerpt, claim, and quote fields are bounded to 4,096, 300, 120, 128, 6,000, 2,000, and 600 code units respectively. Oversized graphs return HTTP 413 rather than a partial graph. Invalid UUIDs return HTTP 400; no authenticated user returns HTTP 401; invalid timestamps or other graph-construction failures return HTTP 422; admin-client creation or database-operation failures return HTTP 503. Auth verifier outages return HTTP 503, while invalid or absent credentials return HTTP 401.

A backward-compatible database constraint migration applies corresponding character and UTF-8 byte limits to new or updated rows while leaving legacy rows available for the route to reject safely. The graph builder also caches each source excerpt's codepoints once per request, even when many claims cite that source. Plain-text fetches are capped at the same 6,000-code-unit excerpt limit as HTML captures before validation and persistence. A reproduced passage is returned whole up to the source excerpt bound; it is never clipped and labeled as reproduced.

Source nodes and claim nodes use the persisted row UUIDs. Source retrieval and claim creation timestamps are preserved. Publication dates are read from `research_sources.published_at` when present, falling back to the saved brief summary source matched by URL. Captures made after the run's `completed_at` are excluded, as are future publication dates, invalid publication dates, and date-only publications from the snapshot day because their intraday order is unknown. The API exposes only the matched quote span from a stored excerpt, never the entire private excerpt.

Edges mean recorded provenance and saved interpretation. `supports`, `challenges`, and `contextualizes` preserve each saved claim's stance relative to the research question; they do not establish that the claim is true. Quote-span reproduction uses the same case-insensitive, collapsed-whitespace matching as brief validation and returns the original captured passage. This proves only that normalized text matches the stored quote. The graph always reports `not_independently_verified` for claim support.
