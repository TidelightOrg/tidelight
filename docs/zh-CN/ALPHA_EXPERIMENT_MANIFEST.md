# Alpha Factory 实验清单

每次新的 Strategy Lab 回测都会将可选且带版本的 `experimentManifest` 与已保存运行一起记录，并包含在公开回放导出中。现有运行仍可读取和发布；保留原有字段，回放界面会标明其早于实验清单。

清单记录引擎版本及可用时的部署修订、策略键/版本、确切市场类别和交易工具、Bitget 数据采集时间、已完成 K 线区间、训练/样本外边界、手续费、滑点、杠杆与资金费率处理。美股永续合约仍按不加杠杆的价格回放建模，并排除资金费率；Reality 现货运行会单独标识。

`dataset.fingerprint` 使用 SHA-256 计算有序的 `ohlcv-v1` 数据行：

```text
[时间戳, 开盘价, 最高价, 最低价, 收盘价, 成交量或 null, 成交额或 null]
```

`integrity.manifestDigest` 对清单中除 `integrity` 之外的字段计算 SHA-256，计算前递归排序对象键。发布带清单的新运行前，服务器会重新计算数据集指纹和清单摘要；归档被修改或格式错误时会拒绝发布。这些摘要可检测不匹配；它们不是数字签名，也不能证明原始数据提供方或策略结果真实。缺失的源代码修订会显示为“未记录”，不会事后推断。

若信号计算、数据分割或执行假设的变化可能影响结果，必须递增引擎版本。各策略键仍单独带版本。清单不会计算执行模型明确排除的成本或风险，包括永续资金费率、杠杆、保证金、强平、股息和订单簿冲击。
