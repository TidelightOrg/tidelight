# ADR 0002: Research evidence stays bounded and public replay stays allowlisted

## Status

Accepted

## Context

Research answers are only as trustworthy as the passages, timestamps, and ownership checks behind them. Public surfaces publish a reviewed subset of a private run.

## Decision

- The RPC checks current opt-in atomically and only returns aggregate counts. No privileged row data is queried or serialized by this endpoint. (`app/api/community/profile/[handle]/route.ts`)
- Status recording remains authoritative if email delivery is unavailable. (`app/api/cron/status-history/route.ts`)
- Supabase pg_net invokes the worker over HTTPS with its Vault-held bearer. (`app/api/cron/tic-research/route.ts`)

- Feedback remains available if optional session lookup fails. (`app/api/feedback/route.ts`)
- Send a separate receipt only to an address the sender explicitly supplied. Keep the feedback body private and avoid promising a response deadline. (`app/api/feedback/route.ts`)
- Keep the model's facts inside the graph passage and persisted source bounds. (`app/api/research/agent-flow/route.ts`)

- Reserve time for the final gates and private record commit under maxDuration. (`app/api/research/agent-flow/route.ts`)
- Validate scope and account-owned context before consuming anonymous capacity. (`app/api/research/agent-flow/route.ts`)
- Reader disconnected. Finish the private record. (`app/api/research/agent-flow/route.ts`)
- Bound each independent provider call so one stalled feed cannot consume the function's full execution window or prevent a source-only research result. (`app/api/research/agent-flow/route.ts`)
- Malformed candles keep this asset's trading gate closed. (`app/api/research/agent-flow/route.ts`)
