# ADR 0011: Database history keeps privileges, retention, and owner scope in the migration

## Status

Accepted

## Context

Applied Supabase migrations are immutable history. Their comments stay in the migration files so checksums do not change. This record is the readable copy of those decisions, including notes on scripts and fixtures that are not applied migrations.

## Consequences

Code no longer repeats these constraints. Change the behavior only by updating this record and the implementation together. Applied migrations under `supabase/migrations/` are not rewritten.
