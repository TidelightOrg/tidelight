# Judge research session storage

Unsigned Judge research can run without an account. When the browser accepts a bounded result in session storage, it can be restored in that tab; the result notice identifies whether that write succeeded. If storage is blocked or the result exceeds the limit, the result stays in memory until navigation or reload. The clear control removes the tab's stored result and dismisses the visible result; a failed removal is reported to the user. Account history requires sign-in and guest results are not saved to an account.
