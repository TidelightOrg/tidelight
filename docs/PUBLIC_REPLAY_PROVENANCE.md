# Public replay quote provenance

Newly published research replays include `quoteSourceUrl` when a displayed quotation matches captured text from an allowed, cited source. The passage offsets refer to Unicode code points in that captured excerpt, not positions on the current live page. The excerpt itself remains private; the public record contains the matched quotation and source metadata. A match confirms text correspondence and does not independently establish that the source supports the claim.

Earlier replay records may lack `quoteSourceUrl`; the page identifies the missing attribution instead of guessing which citation matched. Existing records are not rewritten. Public replay publication remains an authenticated owner action; viewing and Judge Mode remain available without signing in.
