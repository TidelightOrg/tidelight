# Tidelight public evidence manifest

简体中文版：[README.zh-CN.md](README.zh-CN.md)

This directory contains the public evaluator's evidence index. It distinguishes production-verified routes and automated checks from proof artifacts that are still missing or private.

- `manifest.json` — machine-readable evidence inventory.
- `README.md` — scope, limitations, and integrity model.

The manifest is an index, not a claim that Tidelight has profitable alpha or a public multi-week paper-trading record. It intentionally excludes private user and account records.

- `research-monitor-verification-20261026.json` — dated production UI smoke-check, automated-check summary, scope limits, and direct links to public screenshots.
- `/judge#research-monitor-verification` — public Judge section with the production Monitor and Research Flow captures and verification status.
